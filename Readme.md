# Frogger

A simple 2D Frogger-style game built in Godot 4 with GDScript.

Guide your frog across a busy road and river to reach safety — classic arcade action recreated from scratch.

## Play it
🎮 [Play on itch.io]([https://your-username.itch.io/frogger](https://harshtank.itch.io/frogger))

## Controls
| Key | Action |
|-----|--------|
| Arrow Keys / WASD | Move frog |

## Built with
- [Godot Engine 4.7.1](https://godotengine.org/)
- GDScript

## Running locally
1. Clone this repo
2. Open the project folder in Godot 4.7.1
3. Press F5 to run

## Exporting
This project exports to Web (HTML5) for itch.io. See Godot's [export docs](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html) if you want to build it yourself.
